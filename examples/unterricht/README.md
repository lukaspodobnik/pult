# Neutrales Unterrichtsbeispiel

Diese Sequenz zeigt das neue Dateiformat ohne persönliche Unterrichtsdaten.
Unter `sequences/6/mathematik/formatbeispiel/` liegen die Sequenz-Metadaten,
die fünf Stundendateien, eine Aufgabe mit Lösung und eine lokale SVG-Abbildung.

- `stunde.toml`: Titel und geordnete Aufgabenverweise.
- `vorbereitung.md`: freie Notizen, TeX und ein relativ verlinktes Bild.
- `ziele.md`: ungeordnete Lernzielliste.
- `verlauf.md`: Phasen mit #-Überschriften; in PULT als Tabelle dargestellt.
- `material.md`: Materialliste; benannte Datei- oder Webseitenlinks sind erlaubt.

Den vollständigen Vertrag beschreibt die README und
`src/pult/defaults/vorbereitung/materialvertrag.md` im Projekt.
