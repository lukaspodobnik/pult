# Operatoren für Mathematik 5–8

Diese Liste ist eine vereinbarte Formulierungshilfe für die Unterrichtsvorbereitung, keine offizielle Operatorenliste.

| Operator | Was erwartet wird | Beispiel |
| --- | --- | --- |
| **Gib an / Nenne** | Ergebnis oder Information ohne Erläuterung des Lösungswegs. | Gib die Koordinaten des Punktes A an. |
| **Berechne** | Ein Ergebnis rechnerisch ermitteln; den Rechenweg nachvollziehbar notieren, sofern keine Kopfrechenaufgabe vorliegt. | Berechne den Flächeninhalt des Rechtecks. |
| **Bestimme** | Ein Ergebnis mit einem geeigneten Verfahren ermitteln. Das kann rechnerisch, zeichnerisch oder durch Überlegen geschehen. | Bestimme den Schnittpunkt der beiden Geraden. |
| **Schätze** | Einen begründeten Näherungswert angeben. | Schätze die Höhe der Tür. Gib an, welche Vergleichsgröße du verwendest. |
| **Lies ab** | Informationen unmittelbar einer Darstellung entnehmen. | Lies die Nullstelle am Graphen ab. |
| **Zeichne** | Eine genaue Darstellung mit geeigneten Hilfsmitteln anfertigen. | Zeichne den Graphen der Funktion $y=2x+1$. |
| **Skizziere** | Die wesentlichen Eigenschaften einer Darstellung sichtbar machen; Maßstabsgenauigkeit ist nicht erforderlich. | Skizziere ein mögliches Schrägbild des Körpers. |
| **Konstruiere** | Eine geometrische Figur mit den zugelassenen Konstruktionsmitteln erzeugen. | Konstruiere mit Zirkel und Lineal die Mittelsenkrechte der Strecke AB. |
| **Beschreibe** | Eigenschaften, Zusammenhänge oder ein Vorgehen verständlich wiedergeben. | Beschreibe, wie sich der Graph verändert, wenn $t$ größer wird. |
| **Erkläre / Erläutere** | Einen Zusammenhang oder ein Vorgehen verständlich machen; bei Bedarf durch ein Beispiel oder eine Darstellung. | Erkläre an einem Flächenmodell, warum Erweitern den Wert eines Bruchs nicht verändert. |
| **Begründe** | Eine Aussage oder Entscheidung durch nachvollziehbare mathematische Argumente stützen. | Begründe, warum jedes Quadrat auch ein Rechteck ist. |
| **Beweise** | Die allgemeine Gültigkeit einer Aussage durch eine lückenlose mathematische Argumentation zeigen. Einzelne Beispiele genügen nicht. | Beweise, dass die Summe zweier ungerader natürlicher Zahlen gerade ist. |
| **Widerlege** | Zeigen, dass eine Aussage falsch ist; bei einer allgemeinen Aussage genügt ein Gegenbeispiel. | Widerlege: „Wenn ein Rechteck einen größeren Umfang hat, dann hat es auch einen größeren Flächeninhalt.“ |
| **Überprüfe** | Feststellen, ob eine Aussage oder ein Ergebnis zutrifft, und die Prüfung nachvollziehbar machen. | Überprüfe durch Einsetzen, ob $x=4$ die Gleichung löst. |
| **Vergleiche** | Gemeinsamkeiten und Unterschiede anhand der genannten Gesichtspunkte herausarbeiten. | Vergleiche die beiden Lösungswege hinsichtlich Rechenaufwand und Übersichtlichkeit. |
| **Ordne zu** | Elemente anhand ihrer Eigenschaften passend miteinander verbinden. | Ordne jedem Graphen die passende Funktionsgleichung zu. |
| **Stelle auf** | Einen passenden mathematischen Ausdruck formulieren. | Stelle eine Gleichung auf, mit der sich die gesuchte Seitenlänge berechnen lässt. |
| **Forme um / Vereinfache** | Einen Term oder eine Gleichung wert- beziehungsweise lösungsäquivalent verändern; die gewünschte Form beachten. | Vereinfache den Term $3a+2(a-4)$ so weit wie möglich. |
| **Löse** | Alle Lösungen einer Gleichung oder eines Gleichungssystems im angegebenen Bereich ermitteln. | Löse die Gleichung $3x+5=20$. |
| **Interpretiere / Deute** | Die Bedeutung eines mathematischen Ergebnisses oder einer Darstellung im gegebenen Zusammenhang erklären. | Deute die Steigung des Graphen im Zusammenhang mit dem Wasserstand. |
| **Untersuche** | Einer konkreten Fragestellung systematisch nachgehen und das Ergebnis festhalten. | Untersuche, wie sich der Flächeninhalt eines Rechtecks verändert, wenn eine Seite verdoppelt und die andere halbiert wird. |
| **Beurteile** | Eine Aussage oder Vorgehensweise anhand passender Kriterien bewerten und das Urteil begründen. | Beurteile, ob das Diagramm die Entwicklung der Besucherzahlen angemessen darstellt. |

## Anwendung

- Formuliere kurze, altersgerechte Aufgabenstellungen. Benenne eindeutig, was bearbeitet und welches Ergebnis geliefert werden soll. Trenne unterschiedliche Arbeitsaufträge bei Bedarf in Teilaufgaben.
- Keine unnötige sprachliche Feinabstufung: „Erkläre“ und „Erläutere“ dürfen dasselbe bedeuten. Entscheidend ist ein verständlicher Auftrag.
- Nenne ausdrücklich, wenn ein bestimmtes Verfahren, eine Darstellung oder eine Begründung verlangt wird, beispielsweise „Bestimme rechnerisch …“. Verwende „Berechne“ nicht, wenn eigentlich eine Erklärung oder Begründung erwartet wird.
- Ein Operator legt weder Schwierigkeit noch Anforderungsbereich allein fest. Entscheidend sind Aufgabe, Vorwissen und Hilfen.
- Offene Denkimpulse wie „Kann das stimmen?“ oder „Was fällt dir auf?“ sind als Gesprächseinstieg möglich. Bei eigenständig zu bearbeitenden Aufgaben verdeutliche anschließend die Erwartung, etwa „Formuliere eine Vermutung und überprüfe sie an drei Beispielen.“ Vermeide vage Aufträge wie „Beschäftige dich mit …“.

Die Beispiele illustrieren den Operator. Benötigte Abbildungen, Maße, Gleichungen oder sonstige Angaben müssen in der konkreten Aufgabe ergänzt werden.
