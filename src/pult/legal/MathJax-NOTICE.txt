PULT bundles selected MathJax JavaScript modules with a local stdin/stdout wrapper.
Build inputs and instructions are in tools/math-renderer/ in the PULT source repository.
The wrapper and generated SVG sizing are PULT modifications; upstream module code
is included unminified in assets/math-renderer.cjs with module path comments.
